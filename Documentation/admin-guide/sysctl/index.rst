简介
====

Sysctl 是一种在运行时配置内核某些方面的方式,而 /proc/sys/ 目录的
存在让你甚至不需要任何特殊工具就能做到这一点!
事实上,要用好这些配置设施,只需要四样东西:

- 一台运行中的 Linux 系统
- root 权限
- 常识(如今这东西尤其难找)
- 知道那些值都是什么意思

正如快速执行一下 'ls /proc/sys' 所显示的,该目录由若干个(取决于
架构?)子目录组成。每个子目录大体上只关乎内核的一部分,因此你既可以
逐块进行配置,也可以来点“主题式调校”。

本文档涉及的内容:

=============== ===============================================================
abi/            执行域(execution domain)与 personality
<$ARCH>         各种 CPU 架构的调优控制项(如 csky、s390)
crypto/         加密子系统
debug/          调试功能
dev/            设备相关信息(如 dev/cdrom/info)
fs/             特定文件系统
                文件句柄、inode、dentry 与配额(quota)调优
                binfmt_misc <Documentation/admin-guide/binfmt-misc.rst>
kernel/         全局内核信息 / 调优
                杂项
                部分架构特定的控制项
                安全(LSM)相关内容
net/            网络相关内容,文档见:
                <Documentation/networking/>
proc/           <空>
sunrpc/         SUN 远程过程调用(NFS)
user/           每用户命名空间(per-user namespace)限制
vm/             内存管理调优
                缓冲区与缓存管理
xen/            Xen 虚拟机管理程序(hypervisor)控制项
=============== ===============================================================

以上是我在自己的系统上见到的、以及通过翻阅源码发现的子目录。
在其他配置下可能有更多或不同的子目录。如果你发现了别的目录,
真心希望能告诉我 :-)
