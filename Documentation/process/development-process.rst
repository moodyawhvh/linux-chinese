内核开发过程指南
================

本文档旨在帮助开发者(及其管理者)以尽可能少的挫败感融入内核开发社区。它试图记录这个社区的运作方式,让那些对 Linux 内核开发(乃至整个自由软件开发)并不十分熟悉的人也能读懂。文中虽然包含一些技术性内容,但整体上是一次面向开发流程(process)的讨论,无需深入掌握内核编程知识即可理解。
